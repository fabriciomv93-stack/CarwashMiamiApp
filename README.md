# Carwash Miami - Recordatorios de acabado cerámico
App pequeña y separada del sistema administrativo. Guarda clientes localmente, calcula 2 meses + 15 días, programa notificaciones, permite WhatsApp y exportar/restaurar respaldos JSON.
Compilación: Android Gradle Plugin 8.7.3 + Gradle 8.9. Ejecutar `gradle assembleDebug`.
